# Lessons log (append-only, dated)

Add a dated line when a route teaches something general. Route-specific facts stay in the project's memory.

- 2026-09-02: nine-PR route with Claude Code and Codex workers. Reviewer rounds, not coding, dominated cost; three revise rounds per artifact exploded the budget. Dropped to one review round with a blocking label gate. Monitors replaced a dozen background waits. Reviewers mix severity words; gate on a decision line.
- 2026-09-03: bot review loops can take eight rounds on concurrency code; design two-phase claims up front. Interrupting a worker per bot round works but stretches the task. Muse and OpenCode as alternative harnesses: sandbox network, approval modes and prompt queueing differ per harness; probe capabilities before assigning database-backed manual tests. GitHub native stacks link pull requests by integer number with the stacks API.
- 2026-09-22 (launch): a rejected `herdr agent start` still ran and left a stuck pane; close and re-split. `--skip-git-repo-check` is not a Codex flag. Same-tab pane move is a no-op; move out to a temporary tab and back. Prompt `--timeout` needs `--wait`. The Bash tool refuses sleep chains. Workers need the credential helper for fetch, not only push. One Herdr mutation per call; panes first, then agents, then `/goal`.
- 2026-09-22 (running): macOS bash 3 kills `declare -A` monitors silently; check the output file after arming. Codex writes only under `-C`; report paths must be inside it. A coverage rule on a whole package pulls a worker out of scope; scope it to changed files. `herdr tab create --label` works. Claude reviewer launch on claude-fable-5-1 xhigh with `--permission-mode auto --add-dir` is ready in seconds and takes plain prompts. A worker with base-change latitude dissolved a GitHub stack on its own; name allowed GitHub mutations per task.
- 2026-09-22 (first fix round): a Codex worker that ended its turn with a question keeps it as a queued follow-up after the answer arrives as a prompt; Herdr then refuses prompts with `agent_blocked` until the question is skipped (`alt+up`, `ctrl+]`). A watcher that stops watching a pane once its report exists, and exits on ALL-REPORTS, misses fix rounds: watch panes throughout, emit REPORT-UPDATED on mtime change, never exit on its own. Grep-filtering a prompt result for `"type"` hides the error JSON.
- 2026-09-22 14:32 ("Your monitor is not working. Fix for real"): Monitor events do not wake the session between turns; only a finished background Bash command does. The loop's clock is now `scripts/wait-event.sh` (one-shot, exits on the first event or after 540 s with TICK, re-armed on every wake). Verify a watcher by comparing the file's mtime with the event time AND with the time the orchestrator acted.
- 2026-09-22 14:38 to 14:57 (first merges): merge authorization came mid-route ("both the local review and the bot reviewer approve, squash"); the first qualifying merge was refused by a base-branch ruleset that needs a second human approval the author's own account cannot give; the user chose admin bypass; then "remove branch if safe after each merge" (remote branch only, when no open PR is based on it). Context rule: reviewer and implementers alike keep context for a follow-up (compact above 50%) and clear for a new task; Codex `/compact` takes up to 2 min and is refused mid-task. Parallel schema tasks from the same base collide on migration numbers; the second to land regenerates.
- 2026-09-22 17:21 to 20:22 (stacked web PRs): deleting a merged base branch closes every open PR based on it; retarget dependents first and gate the delete on a zero dependent count in the same shell. The cut point of a stacked PR after its base was squash-merged is the base's PRE-rebase head (read it from the base PR's review commit ids), not a merge-base against the moved local branch. Codex workers share one weekly quota per account (`quota_summary` "7d N%"); at 0% a goal stops with "Usage limit reached" and resumes with `/goal resume` after the reset; watch the figure before a long round. A cleared Claude reviewer pane can hold an unsent input line; clear it before the next prompt.
- 2026-09-23 (Opus 5.5 reviewer, Sol-medium workers): prompt the reviewer with the whole task, a named finish line and a stop rule, no "think carefully" (vendor guidance; see claude-reviewer.md). The worker's own bot loop dominated wall time (35 min to 1.5 h); the local review still found a P0 the bot missed. Body-only findings: the orchestrator fixes the PR body and asks for a body-only round. The classifier can refuse an admin merge with no reason; retry once with a description that names the merge gate. Reviewers must not use `git stash` (the stack is shared across worktrees); use a temp commit or a scratch worktree.
- 2026-09-23 (nine-PR day, four workers, two reviewers): parallel schema tasks all take the next migration and ADR number; merge serially and send each remaining PR a rebase goal that regenerates its migration. A worker's REPORT comes before its bot loop ends; dispatch new work only after GOAL-DONE. A `/goal` while an old goal is active opens "Replace current goal" (send enter). Put "WAIT until pullfrog-approval on the new head is SUCCESS" in fix goals. A second Claude reviewer needs its own worktree and test database named in the prompt. Four Codex workers drained the weekly pool from 58 to 11 percent in about five hours; the review bot shares it. A dispatch helper script (`/new`, then the `/goal`, then confirm "Pursuing goal") removes copy errors; macOS bash 3 has no `${x,,}`. The waiter always runs as a background task (user rule).
- 2026-09-23 14:4x: GOAL-DONE does not free a worker; its PR can still fail local review, and the fix round then has no owner. Give new work only after the PR passes local review. Claude reviewers take `/goal` prompts too (user rule): `/clear` for a new PR, `/compact` for a re-review, and the goal says "Find only P0 and P1 issues."
- 2026-09-27 (AAA rebrand, Muse workers, no-commit route): Muse 1.4.0 workers (`muse-spark-1.3` high `--yolo`, launched by the user via pbcopy) take plain prompts, `/clear`, `/compact` and a `/model` picker driven through the pane surface; background jobs make Herdr report idle while work continues (`references/muse-workers.md`).
